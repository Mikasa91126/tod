# 今日事 · 桌面版 2.0 使用说明

> 写给「会用电脑、但不写代码」的人看的说明书。全程照着点就行，不需要敲命令。

## 📌 这是什么

「今日事」是一个装在你本机的待办清单：打开就能记事情、设截止时间、到点被提醒。不用联网、不用注册账号，内容全部留在自己电脑上。

**2.0 版升级成了真正的桌面程序（Electron）**，不再依赖浏览器和启动脚本：

- 🖥️ **原生窗口**：独立应用窗口、任务栏图标是「今日事」自己的图标；
- 📌 **系统托盘常驻**：点窗口右上角 ✕ 会缩到托盘（屏幕右下角），**关掉窗口照样弹提醒**；托盘图标右键有菜单：显示主窗口 / 快速添加任务 / 暂停提醒 1 小时 / 退出；
- 🔔 **双保险弹窗提醒**：到点时 ① 弹 Windows 系统通知（点它可直接跳到那条任务）＋ ② 屏幕右下角弹**置顶提醒窗**（不受「勿扰模式」影响），窗上有「完成 / 稍后 5 / 10 / 30 分钟」按钮，点了立即生效；
- ⏰ **多级日期提醒**：一条任务可以同时设多档提前量（比如「提前 1 天 + 提前 1 小时 + 准点」各响一次），在任务详情或设置里点选标签即可，可叠加；
- 📊 **每日 / 每周回顾**：右侧「统计」标签顶部新增「今日简报」（今天到期、逾期、已完成、专注时长 + 一句话建议）和「本周回顾」（本周完成数、对比上周、最高产的一天、连续打卡）；
- 🚀 **运行更流畅**：任务列表增量渲染（内容没变不重画）、编辑防抖落盘、长列表只渲染屏幕内卡片；
- 💾 **自动备份**：每 5 分钟最多存一份快照到 `backups\`（保留最新 50 份），设置面板里可查看并一键恢复。

## 🚀 怎么用

1. 双击桌面上的「**今日事**」快捷方式（已指向新版）。
2. 第一次启动会自动把旧版的数据接过来（来源是旧版后台的镜像文件），任务列表应该和升级前一样。
3. 想开机自动运行：打开右上角 ⚙️ 设置 → 「桌面行为」→ 打开「开机自动运行」，开机后会自动进入托盘待命。

### 窗口右上角 ✕ 的行为

默认是**最小化到托盘**（推荐）——应用还在后台跑，到点照样提醒。想改成"直接退出"：设置 → 桌面行为 → 关闭窗口时 → 直接退出。
彻底退出：托盘图标右键 → 退出。

## ⏰ 提醒怎么用

1. 选中任务 → 右侧「详情」里设**截止日期 + 时间**。
2. 「🔔 提醒」一排标签**点选多档提前量**（准点 / 提前 5 / 15 / 30 分钟 / 1 / 2 小时 / 1 天），可叠加；再点一次取消。
3. 快捷按钮：15 分钟后 / 1 小时后 / 今晚 20:00；「重要提醒」打开后没处理每 5 分钟重响，最多 6 次。
4. 到点：系统通知 + 置顶弹窗同时出现（窗口开着时则是页内闹钟 + 系统通知）。置顶弹窗上的按钮点了立即生效，不用回到应用。
5. 免打扰：托盘右键「暂停提醒 1 小时」，或设置里的「暂停提醒」。

> **收不到系统通知？** 检查 Windows「设置 → 系统 → 通知」总开关是否打开、勿扰模式是否关闭。就算全被拦了，**置顶弹窗依然会弹**（这就是双保险的意义）。

## 💾 数据存在哪

- **主数据**：应用自己的本地存储里（不联网、不上传）。
- **镜像**：`data\tasks.json`、`data\reminders.json` —— 后台引擎的调度依据。
- **备份**：`backups\todo-*.json`，每 5 分钟最多一份，保留 50 份。恢复：设置 → 备份列表 → 恢复。
- **日志**：`data\desktop.log`（应用日志）、`data\server.log`（旧版遗留，可删）。

## 🧯 出问题了先做两件事

1. 任务管理器（Ctrl+Shift+Esc）里找「今日事 / Electron」进程确认是否在跑；托盘区看有没有图标。
2. 看 `data\desktop.log` 最后几行，把报错告诉帮你排查的人。

## ↩️ 想回旧版怎么办

- 桌面「**今日事（旧版-直开）**」快捷方式保留着，双击即可用旧方式打开（提醒只在页面开着时有效）。
- 迁移前的完整旧文件备份在 `_快照-Electron迁移前-20261001\`。
- 旧版说明文档：`README-桌面版-v1旧架构.md`。
