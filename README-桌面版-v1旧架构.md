# 今日事 · 桌面版使用说明

> 写给「会用电脑、但不写代码」的人看的说明书。全程照着点就行，不需要敲命令。

## 📌 这是什么

「今日事」是一个装在你本机的待办清单：打开就能记事情、设截止时间、到点被提醒。不用联网、不用注册账号，内容全部留在自己电脑上。

这一版它从「一个网页」升级成了「桌面级小应用」：

- 多了一个**后台小服务**，所以**关掉窗口也能弹 Windows 系统通知**；
- 宽窗口变成左右双栏：左边任务列表，右边详情 / 日历 / 统计 / 专注四个标签；
- 新增日历周视图、番茄钟、右键菜单、全键盘操作、自动备份等功能。

**⚠️ 请先记住一句话**：数据以**浏览器本地存储**为准。后台服务只是「任务镜像 + 定时提醒 + 自动备份」，它不会、也不该取代浏览器里的那份数据。所以不要随便清理浏览器数据（见常见问题）。

## ✨ 这次新增了什么

- ⏰ **定时提醒**：任务可设截止日期 + 时间，到点弹提醒；支持「提前 5 / 15 / 30 分钟、1 小时、1 天」。
- 🔔 **重要提醒**：没处理就每 5 分钟重响一次，最多 6 次。
- 🪟 **关掉窗口也能提醒**：由后台服务弹 Windows 系统通知；关机或睡眠错过的提醒，开机后 12 小时内补提醒一次。
- 🧩 **两种运行模式**：装了后台服务是「完整模式」；直接双击 index.html 是「仅浏览器模式」。
- 🖥️ **宽屏双栏布局**：窗口宽度 ≥ 1100px 时展开右侧栏；窗口变窄自动变回单列 + 右侧抽屉。
- 📅 **日历 / 周视图**：月历显示每天的任务数量和分类色点，点某天筛选当天任务，任务卡能拖到日历格子上改期；侧栏顶部还有本周 7 天概览。
- 🍅 **番茄钟**：25 分钟专注（时长可配置），环形倒计时，结束时提醒并记录，可开启「专注结束自动完成任务」。
- 🖱️ **右键菜单**：任务卡上右键可改优先级、改日期、设提醒（15 分钟后 / 1 小时后 / 今晚 20:00）、改分类、开始专注、复制标题、删除；空白处右键可添加任务 / 全部展开 / 全部折叠。
- ⌨️ **全键盘操作**：上下键选任务、空格完成、快捷键切视图、Ctrl+Z 撤销删除等（见下方快捷键总览）。
- 📆 **今日视图**：只看今天该做的 —— 今天到期 + 已逾期 + 没设日期的任务。
- 📊 **增强统计**：完成率环形图、近 7 天完成趋势、连续打卡天数、各分类完成情况。
- 🏷️ **窗口标题与任务栏计数**：标题显示「今日事 (未完成数) · X 项今日到期」，提醒时闪 ⏰，专注时显示剩余时间。
- 💾 **自动备份**：后台每 5 分钟最多存一份任务快照到 `backups\`（保留最新 50 份），设置面板里可查看并一键恢复。
- ⚙️ **设置面板**：右上角齿轮，集中管理提醒默认值、提示音、专注时长、主题、后台服务状态、备份与恢复。
- 🎉 **首次更新提示**：升级后第一次打开会弹一次「新功能」说明，看过就不再弹。

## 🚀 第一次怎么用

1. 双击桌面上的「**今日事**」快捷方式（它现在指向 `启动今日事.ps1`）。
2. 启动器会先探测有没有 Node，然后**在后台悄悄起一个服务**，再用 Edge 的 `--app` 模式打开一个没有地址栏的窗口 —— 这就是完整模式。
3. 想让它开机自动运行：双击文件夹里的「**开机自启-安装.cmd**」；不想要了就双击「**开机自启-取消.cmd**」。
4. 想确认环境是否正常：在文件夹里运行 `node verify.mjs` 自检（可选，纯排错用）。

### 🚚 旧数据迁移（升级后第一次打开，任务列表可能是空的）

**别慌，数据没丢。** 原因很简单：数据存在浏览器里，而「直接双击 index.html 打开」和「通过后台服务打开」在浏览器看来是**两个不同的网站**，各自的存储互不相通。旧任务还躺在旧的那一边。

迁移步骤：

1. 确认后台服务正在运行（用「今日事」快捷方式打开过一次即可）。
2. 双击桌面上保留下来的「**今日事（旧版-直开）**」快捷方式，它会用旧方式打开页面。
3. 只要后台服务在运行，这个页面就会自动把旧数据**同步给后台**（后台这时相当于中转站）。
4. 回到新窗口（「今日事」），刷新页面，任务就回来了。
5. 确认新窗口里数据齐全后，「今日事（旧版-直开）」就可以留着不管，或者删掉。

> 如果刷新后仍然没有任务：先确认第 1 步的服务确实在跑（打开设置面板看「后台服务状态」），再重复第 2～4 步。

## 🧭 界面速览

打开后你会看到这么几块：

- **顶部**：输入框（写任务的地方）和筛选栏（全部 / 未完成 / 已完成，以及「今天」）。
- **中间偏左**：任务列表。每张任务卡上有完成圆圈、标题、日期、分类色点和优先级。
- **右侧栏**（窗口够宽时才展开）：**详情 / 日历 / 统计 / 专注** 四个标签，点标签切换。
- **右上角**：设置齿轮（搜索和主题切换也都有快捷键）。
- **窗口标题栏**：显示「今日事 (未完成数) · X 项今日到期」，提醒时会闪 ⏰，专注时显示剩余时间。
- **只有仅浏览器模式才会出现**：页面顶部一条黄色提示条，提醒你后台服务没在跑。

## 🖱️ 日常怎么用

- **记一件事**：在顶部输入框写下来回车；右侧可选日期、分类、优先级。
- **完成任务**：点任务左边的圆圈，或选中后按空格。
- **改任务**：单击任务卡选中，右侧「详情」标签里改标题、备注、日期、分类、优先级、提醒。
- **看今天**：筛选栏点「今天」，只看今天到期 + 已逾期 + 没设日期的任务。
- **看日历**：右侧栏切到「日历」标签。月历格子上有每天的任务数量和分类色点，点某天就筛选那天；把任务卡**拖到格子上**可以直接改期。标签顶部是本周 7 天概览。
- **开番茄钟**：右侧栏切到「专注」标签，或按 P。默认 25 分钟，环形倒计时，结束会提醒并记录一次专注；可在设置里打开「专注结束自动完成任务」。专注结束的时刻也会交给后台，所以关掉窗口也能收到提醒。
- **看统计**：右侧栏「统计」标签，有完成率环形图、近 7 天完成趋势、连续打卡天数、各分类完成情况。
- **右键菜单**：任务卡上右键 → 改优先级 / 改日期 / 设提醒（15 分钟后、1 小时后、今晚 20:00）/ 改分类 / 开始专注 / 复制标题 / 删除；空白处右键 → 添加任务 / 全部展开 / 全部折叠。
- **搜索**：按 Ctrl+K 或 Ctrl+F，直接敲关键词。
- **换主题 / 紧凑模式**：Ctrl+Shift+D 切换浅色深色；紧凑模式在设置面板里开。
- **窗口变窄了？** 宽度小于 1100px 时会自动变成单列，右侧内容收进抽屉，点按钮展开即可，功能不缩水。
- **设置**：右上角齿轮。里面有默认提醒时间、默认提前量、提示音（可选可试听）、重要提醒默认值、错过补提醒时长、专注时长、主题、紧凑模式、后台服务状态、备份列表与一键恢复。
- **误删了？** 按 Ctrl+Z 撤销删除。

## ⏰ 定时提醒怎么用

1. 选中任务 → 右侧「详情」里设**截止日期 + 时间**（比如今天 20:00）。
2. 需要的话再设**提前量**：提前 5 / 15 / 30 分钟、1 小时或 1 天先提醒一次。
3. 重要的事打开「**重要提醒**」：到点没处理就每 5 分钟重响一次，最多 6 次。
4. 到点会弹出提醒窗，里面可以选「**完成 / 稍后 5 分钟 / 稍后 10 分钟 / 稍后 30 分钟 / 关闭**」。
5. **关掉窗口也能提醒**：完整模式下由后台服务弹 Windows 系统通知；电脑关机或睡眠错过的提醒，开机后 12 小时内补提醒一次。
6. 想少被打扰：把默认提醒时间、默认提前量、提示音、重要提醒默认值、错过补提醒时长都在设置面板里调好，以后新建任务就按默认来。

提醒窗里的四个按钮分别是什么意思：

| 按钮 | 效果 |
| --- | --- |
| 完成 | 直接把这件事标记为完成，不再提醒 |
| 稍后 5 / 10 / 30 分钟 | 先放一放，到点再提醒一次 |
| 关闭 | 这次提醒到此为止（任务本身不变） |

> 只开了「仅浏览器模式」时，提醒只在页面开着的时候有效。

## 🧩 两种模式的区别

| | 完整模式（推荐） | 仅浏览器模式 |
| --- | --- | --- |
| 怎么进入 | 双击「今日事」快捷方式 / `启动今日事.cmd` | 直接双击 `index.html` |
| 提醒方式 | 页面提醒 + Windows 系统通知 | 只有页面开着时的页面内提醒 |
| 关掉窗口后 | 仍会提醒、仍会备份 | 不再提醒，也不备份 |
| 界面提示 | 无 | 页面顶部有一条黄色提示条 |
| 数据位置 | 后台服务地址下的浏览器存储 | 直接打开文件的存储（与左边不互通） |
| 适合 | 日常使用 | 没装 Node，或临时看一眼 |

## 💾 数据存在哪 / 怎么备份恢复

- **正式数据**：存在浏览器分配给这个应用的**本地存储**里（不联网、不上传）。换浏览器、换电脑、换一个打开地址，都看不到同一份数据。
- **后台镜像**：`data\tasks.json`、`data\reminders.json` —— 后台服务记录的任务镜像和提醒安排，方便它独立弹提醒。**它们不是权威数据**，页面里的那份才是。
- **自动备份**：后台服务每 5 分钟最多存一份快照到 `backups\todo-*.json`，只保留最新 50 份。
- **恢复**：设置面板 →「备份」列表 → 选一份 → 一键恢复。
- **排错**：`data\server.log` 是后台服务的日志，出问题时看它。

## 🧯 出问题了先做这三件事

1. **保证还能记事**：直接双击 `index.html`，页面照样能用（仅浏览器模式），先别耽误正事。
2. **看服务状态**：打开设置面板看「后台服务状态」；如果没连上，双击「今日事」重新启动一次。
3. **留证据**：看 `data\server.log` 的最后几行，或者运行 `node verify.mjs` 自检，把结果告诉帮你排查的人。

## ❓ 常见问题

**Q：电脑上没装 Node 怎么办？**
A：照样能用。直接双击 `index.html` 进入「仅浏览器模式」，记事情、日历、番茄钟、页面内提醒都在，只是关掉窗口后不再提醒、没有系统通知、没有自动备份。想要完整功能，就去 Node 官网下载 LTS 版一路「下一步」装好，再双击「今日事」。

**Q：双击「今日事」没反应 / 窗口一闪就没了？**
A：先确认装没装 Node（没装时启动脚本会提示后自动关闭）；再试试右键「以管理员身份运行」；还是不行就打开 `data\server.log` 看最后几行报错，或运行 `node verify.mjs` 自检。这期间可以随时直接双击 `index.html` 应急。

**Q：收不到 Windows 系统通知？**
A：按顺序检查三点：① Windows「设置 → 系统 → 通知」里通知总开关是否打开、是否允许应用发通知；② **关闭「勿扰模式 / 专注助手（Focus Assist）」** —— 它会静默拦掉通知，全屏游戏或演示模式也会自动打开它；③ 打开设置面板看「后台服务状态」是否正常。

**Q：关掉窗口还会提醒吗？**
A：完整模式下会 —— 后台服务一直在跑，到点弹 Windows 系统通知。仅浏览器模式不会。

**Q：为什么设置面板显示后台服务没连上？**
A：说明后台服务没在跑：可能没装 Node、可能没通过「今日事」快捷方式打开、也可能 `node.exe` 被结束了。双击「今日事」重新启动即可；这期间页面仍然能用，只是退回仅浏览器模式。

**Q：提示端口被占用 / 启动失败？**
A：通常说明**已经有一个后台服务在运行了**（比如重复双击了启动脚本），不用再启动，直接用「今日事」快捷方式打开窗口即可。确实要重启，就先按下面那条「怎么彻底停止后台服务」结束旧的 `node.exe`。

**Q：怎么彻底停止后台服务？**
A：按 Ctrl+Shift+Esc 打开任务管理器 → 「详细信息」→ 找到 `node.exe` → 结束任务。结束后不再有系统通知和自动备份，页面相当于退回「仅浏览器模式」；下次双击「今日事」会重新起来。

**Q：怎么卸载 / 取消开机自启？**
A：取消自启：双击「**开机自启-取消.cmd**」。彻底不用了：先取消自启 → 结束 `node.exe` → 删除整个 `tod` 文件夹（想留后路的话，先把 `backups` 里的 json 复制到别处）。

**Q：数据会不会丢？**
A：正常情况下不会：数据在浏览器本地存储里，后台每 5 分钟还会自动留一份快照。但请注意：**浏览器「清除浏览数据 / 清除站点数据」以及一些清理软件会把主数据一起清掉**，清理前先确认设置面板里的备份是最新的。

**Q：换电脑 / 换浏览器，任务会跟过去吗？**
A：不会自动同步，数据只在本机这个浏览器里。换电脑时可以把整个 `tod` 文件夹拷过去，新电脑装好 Node 后启动，再到设置面板里用 `backups` 里的快照恢复。

**Q：升级后第一次打开，任务列表是空的？**
A：见上面「🚚 旧数据迁移」，按那 5 步走一遍就好。

**Q：能同时开着旧窗口和新窗口吗？**
A：可以，但两边看到的是两份互不相通的数据（原因同「旧数据迁移」）。日常建议只用「今日事」这一个窗口。

**Q：提醒到点了，但我当时不在电脑前？**
A：如果是关机或睡眠期间错过的提醒，开机后 12 小时内会补提醒一次。

**Q：专注计时中途关掉窗口会怎样？**
A：专注结束的时刻已经交给后台，所以到点仍然会收到 Windows 系统通知（完整模式下）。

**Q：点「稍后」之后还会再提醒吗？**
A：会，在你选的 5 / 10 / 30 分钟后再次提醒；选「关闭」则这次提醒结束。

**Q：提醒响了太多次？**
A：那是「重要提醒」在起作用（每 5 分钟一次，最多 6 次）。在提醒窗点「关闭」即可停止；也可以在任务详情里关掉「重要提醒」。

**Q：那个「新功能」弹窗每次都弹吗？**
A：不会，只在升级后第一次打开时弹一次，看过就不再出现。

## 📁 文件清单说明

| 文件 / 文件夹 | 作用 | 备注 |
| --- | --- | --- |
| `index.html` | 应用本体，**唯一的数据权威** | 不要删 |
| `server.js` | 后台小服务：提醒调度、系统通知、任务镜像、自动备份 | 不要删，删了只剩仅浏览器模式 |
| `启动今日事.cmd` / `启动今日事.ps1` | 双击入口：探测 Node → 后台起服务 → 用 Edge 无地址栏窗口打开 | 不要删 |
| `开机自启-安装.cmd` / `开机自启-取消.cmd` | 安装 / 取消开机自启 | 按需使用 |
| `verify.mjs` | 自检脚本（`node verify.mjs`） | 排错时用 |
| `app.ico` | 应用图标 | 快捷方式在用 |
| `data\tasks.json` | 后台的任务镜像 | 可删，会自动重建（镜像会暂时为空） |
| `data\reminders.json` | 后台的提醒安排 | 可删，会自动重建 |
| `data\server.log` | 后台日志 | 排错用，可删 |
| `backups\todo-*.json` | 自动备份快照（最新 50 份） | **建议保留** |
| `index.html.bak-…` | 升级前旧版页面的备份 | 确认新版正常后可删 |
| 桌面「今日事」快捷方式 | 指向 `启动今日事.cmd` | 日常用这个 |
| 桌面「今日事（旧版-直开）」 | 旧的直开 index.html 的快捷方式 | 迁移旧数据时用 |
